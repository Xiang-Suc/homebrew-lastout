# Lastout Homebrew tap

```bash
brew install --cask xiang-suc/lastout/lastout
```

Installs Lastout.app into /Applications and links its `lo` and `lastout-shell`
command-line tools. The cask is generated by each release
(`app/macos/scripts/release-pipeline.sh` in the source repository) and points at
the zip published on https://github.com/Xiang-Suc/lastout-releases/releases.
